# Self Learning AI Agent

A modular AI Agent built from scratch in Python.

This project is not just another chatbot. The goal is to understand how modern AI agents (OpenAI Agents, AutoGPT, Claude Code, LangGraph, CrewAI, etc.) work internally by implementing every major component ourselves instead of relying on frameworks.

---

# Project Goal

Build an intelligent AI agent capable of:

- Planning tasks
- Choosing tools dynamically
- Executing multi-step workflows
- Remembering user information
- Reflecting on failures
- Generating responses
- Eventually learning and improving over time

Every component is implemented independently to understand the architecture of modern autonomous AI systems.

---

# Current Features

## Planner

Uses an LLM to convert a user request into an execution plan.

Example:

User:

```
Summarize this PDF
```

Planner Output:

```json
{
  "steps": [
    {
      "tool": "pdf_reader",
      "args": {
        "pdf_path": "sample.pdf"
      }
    },
    {
      "tool": "summarizer",
      "args": {
        "text": "{{step_1}}"
      }
    }
  ]
}
```

---

## Executor

Runs every step generated by the planner.

Responsibilities:

- Execute tools
- Resolve arguments
- Handle step outputs
- Store results

---

## Dynamic Tool Chaining

Tool outputs can be passed directly into future steps.

Example:

```json
{
    "text": "{{step_1}}"
}
```

During execution:

```
step_1
↓

PDF Text

↓

Summarizer
```

---

## Tool Manager

Acts as the registry of available tools.

Current tools:

- Echo
- PDF Reader
- Summarizer
- Calculator
- Web Search
- Python Executor
- File Writer
- Memory Store
- Memory Search

Adding a new tool only requires:

1. Create tool
2. Register tool

No planner or executor changes required.

---

## Memory System

The agent has persistent memory.

Information can be stored:

```
Favorite Language = Python
```

Later:

```
What is my favorite programming language?
```

Response:

```
Python
```

Memory is currently stored inside

```
data/memory.json
```

---

## Reflection

After execution the agent evaluates whether the task succeeded.

Reflection determines:

- Success
- Failure
- Confidence

This will later be used for replanning.

---

## Response Generator

Builds the final response shown to the user using the outputs generated by the execution pipeline.

# Why Build This?

Most AI frameworks hide the internal architecture.

This project focuses on implementing every component manually to understand:

- How agents think
- How planning works
- How tools are selected
- How memory works
- How reflection improves execution
- How autonomous AI systems are designed

Instead of treating AI agents as black boxes, this project builds one component by component.
